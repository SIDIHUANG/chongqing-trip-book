# 重庆 10.5-10.10 互动旅行册

## 手机在线分享

将本目录中的文件部署到任意支持 HTTPS 的静态网站后，把网站地址发给同行者即可。推荐使用 GitHub Pages、Cloudflare Pages 或 Netlify 的静态托管，不需要后端。

在线版支持：

- 方案 A/B、日期、上午/中午/下午/晚上的三层切换
- 分享当前视图，链接会保留方案、日期和时段
- 浏览器支持时安装为手机主屏幕旅行册
- 在线时使用高德、百度或 OpenStreetMap 地图
- 访问过的页面、脚本和图片会由 Service Worker 缓存

## 本机预览

在本目录打开终端运行：

```powershell
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。Service Worker 需要 `localhost` 或 HTTPS；直接双击 `index.html` 时，文字、选项和外链仍可用，但浏览器不会启用自动离线缓存。

## 文件分享

直接发送整个 `chongqing-trip-book` 文件夹或压缩包即可。同行者双击 `index.html` 可以查看计划；没有网络或地图 Key 时，地图区域会自动显示当前时段的离线路线顺序，地点节点仍可在联网后打开高德地图。

## 地图与隐私

高德 Key、securityJsCode 和百度 AK 不写入本目录，页面只保存在使用者自己的浏览器 localStorage。分享给同行者时，他们需要使用自己的地图 Key，或者选择 OpenStreetMap。

地图 API 和在线瓦片需要网络；离线旅行册不承诺提供实时道路、拥堵、导航或地图底图。出发前建议在线打开一次需要的图片和地图，并保存关键交通、车次和酒店页面。
